# 论文查重管理系统 — 业务逻辑与数据流转文档

## 1. 系统总览

```
┌──────────────────────────────────────────────────────────────────────┐
│                        论文查重管理系统                                  │
│                                                                      │
│  角色: 学生(Student) │ 教师(Teacher) │ 管理员(Admin)                    │
│  技术: Spring Boot 3.5.7 + MyBatis-Plus + Spring Security + JWT       │
```

## 2. 核心业务流程

### 2.1 论文全生命周期

```
                     ┌─────────┐
                     │  DRAFT   │  学生创建论文草稿
                     │  草稿    │
                     └────┬────┘
                          │ 提交论文
                          ▼
                     ┌─────────┐
                     │SUBMITTED│  论文已提交
                     │  已提交  │
                     └────┬────┘
                          │ 自动分配指导老师
                          ▼
                     ┌─────────┐
                     │ PENDING │  等待教师确认
                     │ 待确认   │
                     └────┬────┘
                          │
                ┌─────────┼─────────┐
                │ 教师确认           │ 教师拒绝
                ▼                   ▼
           ┌─────────┐        ┌──────────┐
           │CHECKING │        │ REJECTED │─── 学生修改后重新提交 → SUBMITTED
           │ 待查重   │        │  已驳回   │
           └────┬────┘        └──────────┘
                │ 创建查重任务
                ▼
           ┌─────────┐
           │ 查重中   │  Tika文本提取 → SimHash → 余弦相似度
           │ 10%→100%│  WebSocket 实时推送进度
           └────┬────┘
                │
      ┌─────────┼─────────┐
      │ 重复率≤20%          │ 重复率>20%
      ▼                    ▼
 ┌─────────┐         ┌──────────┐
 │AUDITING │         │ REJECTED │─── 学生修改后重新提交
 │ 待审核   │         │  不合格   │
 └────┬────┘         └──────────┘
      │
 ┌────┼────┐
 │ 教师通过  │ 教师驳回
 ▼         ▼
┌──────┐ ┌──────────┐
│PASS  │ │ REJECTED │─── 学生修改后重新提交
│ 通过  │ │  不合格   │
└──────┘ └──────────┘
```

### 2.2 状态流转表

| 源状态 | 触发事件 | 目标状态 | 执行者 |
|--------|----------|----------|--------|
| — | 创建论文 | DRAFT | 学生 |
| DRAFT | 提交论文 | SUBMITTED | 学生 |
| SUBMITTED | 自动分配 | PENDING | 系统 |
| PENDING | 教师确认 | CHECKING | 教师 |
| PENDING | 教师拒绝 | REJECTED | 教师 |
| PENDING | 超时未确认 | REJECTED | 系统 |
| CHECKING | 查重完成(≤阈值) | AUDITING | 系统 |
| CHECKING | 查重完成(>阈值) | REJECTED | 系统 |
| AUDITING | 教师审核通过 | PASS | 教师 |
| AUDITING | 教师驳回 | REJECTED | 教师 |
| REJECTED | 学生重新提交 | SUBMITTED | 学生 |
| — | 学生撤回 | WITHDRAWN | 学生 |

## 4. 核心数据表关系

```
sys_user (用户主表)
  ├── 1:1 ── student_info (学生详情: 学号/年级/学院/专业)
  ├── 1:1 ── teacher_info (教师详情: 职称/研究方向/当前指导学生数)
  └── 1:N ── sys_login_log (登录日志)

paper_info (论文主表)
  ├── N:1 ── sys_user.student_id (所属学生)
  ├── N:1 ── sys_user.teacher_id (指导老师)
  ├── N:1 ── college (学院)
  ├── N:1 ── major (专业)
  ├── 1:N ── paper_submit (提交版本记录)
  ├── 1:N ── check_task (查重任务)
  ├── 1:N ── check_result (查重结果)
  ├── 1:N ── check_report (查重报告)
  ├── 1:N ── paper_advisor_rel (指导关系)
  ├── 1:N ── review_record (审核记录)
  └── 1:N ── paper_status_log (状态变更日志)

check_task (查重任务)
  ├── N:1 ── paper_info (论文)
  ├── 1:1 ── check_result (查重结果)
  └── N:1 ── check_rule (查重规则)

file_info (文件信息)
  ├── 存储方式: MinIO(默认) / 本地文件系统
  └── N:1 ── paper_info (关联论文)
```

## 5. 关键业务规则

### 5.1 查重规则
| 规则 | 默认值 | 说明 |
|------|--------|------|
| 每篇论文最大查重次数 | 5次 | 超过后禁止再次查重 |
| 两次查重最小间隔 | 300秒 | 防止频繁提交 |
| 合格阈值 | 20% | 重复率≤20%进入审核，>20%驳回 |
| SimHash位数 | 64位 | MD5哈希降维 |
| 海明距离阈值 | 3 | ≤3视为候选相似，>3直接跳过 |
| N-gram窗口 | 13字符 | 模拟知网连续重复检测 |
| 综合相似度权重 | 词级70% + 字符级30% | — |

### 5.2 指导老师分配规则
| 规则 | 默认值 | 说明 |
|------|--------|------|
| 每位教师最大指导学生数 | 10人 | 达到上限后不再分配 |
| 分配失败重试次数 | 3次 | 排除已拒绝教师 |
| 优先匹配策略 | 同学院 > 同专业 > 研究方向关键字 | 打分排序 |
| 确认超时 | 系统自动拒绝并重新分配 | — |

### 5.3 文件处理规则
| 规则 | 默认值 | 说明 |
|------|--------|------|
| 上传文件大小上限 | 50MB | — |
| 论文文件大小上限 | 200MB | — |
| 支持格式 | doc/docx/pdf/txt | Apache Tika提取文本 |
| 审核附件格式 | doc/docx/pdf/jpg/png | — |
| 附件大小上限 | 50MB | — |
| 病毒扫描 | 可选(ClamAV) | 默认关闭 |

### 5.4 安全规则
| 规则 | 值 |
|------|-----|
| JWT有效期 | 24小时 |
| 密码加密 | BCrypt |
| 登录限流 | 10次/60秒 (同一IP) |
| 忘记密码限流 | 3次/300秒 |
| 文件上传限流 | 20次/60秒 |
| 验证码有效期 | 5分钟 (Redis) |
| 预览Token有效期 | 5分钟 (Redis) |
